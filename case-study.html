01

The Problem: Static PDF Manuals vs. Generative Chaos

In modern enterprise marketing, organizations face a paradoxical tension: teams use AI to generate copy, social posts, and visual mockups 10x faster, but the risk of regulatory non-compliance and brand dilution skyrockets.

✗ The Status Quo Pain Points
  • • 50-Page PDF Manuals: Buried in Google Drive; copywriters and devs rarely cross-check them.
  • • Regulatory Fines: In fintech and health, buzzwords like "guaranteed returns" or "chemical peel" trigger instant FTC/SEC scrutiny.
  • • Visual Style Drift: Diffusion models (Midjourney/Flux) default to generic CGI aesthetics without strict brand prompts.
✓ The BrandBrain Solution
  • • Active Context: Brand rules live natively inside Claude Desktop and Cursor via Model Context Protocol.
  • • Hybridized Guardrails: Regex boundary detection guarantees zero false negatives on prohibited terms.
  • • Instant Art Direction: Generates camera specs, Kelvin lighting, and exact hex swatches on demand.

Key Engineering Edge Cases & Solutions

1. Multi-Model Resilience & Regional Fallback in Bedrock

In AWS Bedrock Europe (Stockholm eu-north-1), foundation models often require cross-region inference profiles (eu.anthropic.claude-sonnet-4-6), while preview models throw AccessDeniedException. We implemented an automatic candidate resolver in BedrockClient.converse() that gracefully cascades through active models without disrupting user sessions.

2. BYOK Privacy & Zero Secret Leakage

In compliance with open-source security best practices, the server adopts a Bring Your Own Key (BYOK) model. Real AWS keys live exclusively in the local .env (ignored by Git). Public repositories and GitHub Pages contain only dummy templates. Developers hosting the server bear zero external token liability.

3. Deterministic + LLM Hybrid Guardrails

Pure LLM evaluators can suffer from prompt injection or leniency. BrandBrain executes deterministic regex pattern matching on banned phrases before calling Bedrock. If a banned phrase is detected, the audit score is capped under 60 and marked as FAIL, guaranteeing zero false negatives.

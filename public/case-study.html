01

The Problem: 50-Page PDFs vs. Generative Chaos

Modern creative, product, and growth teams leverage generative AI to create marketing collateral, social campaigns, and UI mockups 10x faster. However, this velocity introduces an existential operational challenge: brand dilution and regulatory non-compliance at scale.

✗ The Status Quo (Static Manuals)
  • • Buried PDF Guidelines: 60-page PDF brand manuals gather dust in Google Drive; engineers and copywriters rarely reference them during drafting.
  • • Regulatory Exposure: In regulated industries (fintech, healthcare, automotive), casual marketing claims like "guaranteed returns" or "chemical peel" trigger instant SEC, FTC, or EU compliance penalties.
  • • Visual Style Drift: Diffusion models (Midjourney, Stable Diffusion, Flux) generate generic CGI hyper-gloss unless prompted with exact Kelvin lighting, camera sensor specs, and approved hex codes.
  • • Manual Review Bottleneck: Creative directors spend 40% of their week proofing junior copy and correcting off-brand assets.
✓ The BrandBrain-MCP Solution
  • • Contextual In-IDE Governance: Brand rules live directly inside Claude Desktop, Antigravity, and Cursor via the Model Context Protocol.
  • • Hybridized Deterministic Guardrails: Regex boundary scanning ensures zero false negatives on prohibited regulatory keywords before LLM inference.
  • • Automated Diffusion Art Direction: Generates ready-to-run Midjourney and Flux prompts with exact hex color constraints, camera lenses, and negative prompt filtering.
  • • Zero-Overhead Deployment: FastMCP stdio architecture runs locally with Bring Your Own Key (BYOK) privacy—no SaaS lock-in or subscription costs.

Architecture: FastMCP over Stdio Transport

BrandBrain-MCP is designed as a modular Python service built on the official FastMCP SDK. By communicating over standard I/O (JSON-RPC over stdio), it runs natively inside developer environments with sub-millisecond local process handshakes.

05

Key Engineering Edge Cases & Solutions

01 Bedrock Regional Model Cascade (eu-north-1)

In AWS Bedrock Stockholm (eu-north-1), foundation models often require cross-region inference profiles (eu.anthropic.claude-sonnet-4-6), while preview models throw AccessDeniedException. We built an automatic cascade resolver in BedrockClient.converse() that gracefully attempts primary inference and falls back without interrupting client sessions.

02 Bring-Your-Own-Key (BYOK) Security Isolation

Corporate brand knowledge and marketing drafts must never be leaked to third-party SaaS caches. BrandBrain adopts strict BYOK: AWS credentials reside only in the user's local .env (ignored by Git). The MCP server runs as a local child process; no cloud server or external API relay touches the developer's secrets.

03 Hybrid Guardrail Defense (Regex + LLM)

Pure LLM evaluators can hallucinate or succumb to prompt injections in creative copy. BrandBrain implements a two-stage hybrid pipeline: Deterministic regex scanning runs first over client-specific banned vocabularies. If prohibited terms are flagged, compliance status is hard-locked to FAIL with score ≤ 60 before Claude Sonnet evaluates qualitative nuance.

04 ChromaDB Metadata Scoping & Cosine Distance

Multi-tenant brand contamination is catastrophic in enterprise environments. BrandBrain structures ChromaDB collections with strict metadata filtering on client_id and category. Semantic queries for Solaris never retrieve Velvet Apothecary guidelines, even under high concurrency.

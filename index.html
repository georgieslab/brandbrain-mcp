System Architecture

      
Zero-latency context protocol bridging IDE clients to enterprise cloud inference

    


    

      

        

          01
        

        
Desktop Client Layer

        

          Claude Desktop, Antigravity, or Cursor launch python -m src.server as a child subprocess communicating bidirectionally over standard input/output (stdio).
        

      


      

        

          02
        

        
ChromaDB Vector Store

        

          Embeds client rules, forbidden terms, color palettes, and art directions using Amazon Titan Text Embeddings V2 (1024 dimensions) with deterministic local fallback.
        

      


      

        

          03
        

        
AWS Bedrock Reasoning

        

          Claude Sonnet evaluates tone compliance, verifies regulatory boundaries, and engineers high-craft diffusion specs in strictly validated JSON schemas.
        

      

    

  


  
  

    

      
Client Integration Config

      
Paste this configuration directly into Claude Desktop or Antigravity MCP settings

    


    

      

        mcp_config.json
        
      

      
{
  "mcpServers": {
    "brandbrain-mcp": {
      "command": "python",
      "args": ["-m", "src.server"],
      "env": {
        "AWS_ACCESS_KEY_ID": "YOUR_AWS_ACCESS_KEY_ID",
        "AWS_SECRET_ACCESS_KEY": "YOUR_AWS_SECRET_ACCESS_KEY",
        "AWS_DEFAULT_REGION": "eu-north-1",
        "BEDROCK_MODEL_ID": "anthropic.claude-sonnet-5",
        "BEDROCK_EMBEDDING_MODEL_ID": "amazon.titan-embed-text-v2:0",
        "CHROMA_PERSIST_DIR": "./data/chroma_db",
        "EMBEDDING_FALLBACK_LOCAL": "true"
      }
    }
  }
}
